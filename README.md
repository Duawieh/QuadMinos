# QuadMinos!

## 项目简介

QuadMinos! 是一款运行在 Android 平台的局域网联机俄罗斯方块游戏，作为一个练习作品，它将不具备商业性质。

本仓库为 QuadMinos! 的开发者仓库，包含该项目的源代码及其他素材等整体可编译为最终产品的所有资产，用于多人（多机）协作开发。

## 开发人员手册

### 开发环境

- Visual Studio
- Visual Studio Code

您可以在项目文件中找到关于它们的配置文件，这些配置都不包含在忽略规则内。

### 忽略规则

您在与远程仓库进行同步时，应当注意**符合以下条件的文件（文件夹）必须加入忽略规则**：

- 编译产生的文件
- 临时生成的缓存
- 日志文件
- '*.fbx'、'*.wav' 等所有外部素材文件（被包含在 '**/Assets/' 内的文件除外）
