# QuadMinos!

## 项目简介

QuadMinos! 是一款运行在 Android 平台的局域网联机俄罗斯方块游戏，作为一个练习作品，它将不具备商业性质。

本仓库为 QuadMinos! 的开发者仓库，包含该项目的源代码及其他素材等整体可编译为最终产品的所有资产，用于多人（多机）协作。
